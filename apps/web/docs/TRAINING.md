# EITF HRMS — Training Documentation

## Audience tracks

| Track | Duration (suggest) | Focus |
|---|---|---|
| Employee | 45–60 min | ESS, attendance, leave, payslips, tickets |
| Manager | 60–90 min | Approvals inbox, team attendance, performance |
| HR | half day | Employees, leave/attendance rules, onboarding, exit, workflows, security |
| Finance | half day | CTC, payroll cycle, ESD/loans, compliance exports |
| CEO / Admin | 60 min | Analytics, security, integrations, AI assistant |

## Recommended agenda

### 1. Orientation (all)
- Why rules live in Company Settings
- Roles & least privilege
- How to get help (Helpdesk + Ask HR AI)

### 2. Employee lab
1. Login → mark attendance  
2. Apply leave → see balances  
3. Open payslip  
4. Raise a ticket  

### 3. Manager lab
1. Approve a pending leave/loan from Approvals  
2. Review team attendance on mobile  

### 4. HR lab
1. Create employee → start onboarding  
2. Adjust a company setting (e.g. grace minutes) and show effect  
3. Configure a workflow chain  
4. Run a backup / view audit log  

### 5. Finance lab
1. Assign CTC → generate payroll → lock  
2. Open Compliance → PF / salary register export  
3. Review AI anomaly panel  

### 6. CEO lab
1. Analytics + AI predictions  
2. Security: session timeout / 2FA toggle (demo carefully)  
3. Reports → Generate Summary  

## Practice accounts

Use seeded CEO for admin demos; create temporary employees with `Temp@1234`-style passwords and delete after training.

## Assessment checklist

- [ ] Employee can punch and apply leave without HR help  
- [ ] Manager can clear Approvals inbox  
- [ ] HR can start onboarding and find audit events  
- [ ] Finance can generate and export a payroll period  
- [ ] CEO can open Analytics and Security
